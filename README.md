## העלאה לאוויר

### ✅ הדרך שעבדה: קובץ ZIP ל-Netlify Drop

```bash
python research/make_zip.py
```
יוצר `magalei-olamot-site.zip` עם **`index.html` בשורש הארכיון** — גוררים אותו ל-`app.netlify.com/drop` ומקבלים כתובת חיה.

> ⚠️ **אל תגררו תיקייה.** גרירת `World explorers` נכשלת כי אין בשורש `index.html`. גרירת `site` עלולה להיעטף בתת-תיקייה. **ה-ZIP מסיר את הספק.**

`research/verify_zip.py` מאמת שכל נתיב שהעמוד מבקש קיים בארכיון לפני העלאה.

## מה עוד צריך לפני עלייה לאוויר

### 1. ⚠️ הטופס — מצב זמני
כרגע הטופס **פותח וואטסאפ עם כל הפרטים שהמבקר מילא**, כתובים ומסודרים. זה עובד ולא מאבד אף פנייה — אבל לא נשמר לשום מסד נתונים.

לחיבור אמיתי (מייל + ארכיון), הכי פשוט [Web3Forms](https://web3forms.com) או [Formspree](https://formspree.io) — חינם, שתי שורות:

```html
<form action="https://api.web3forms.com/submit" method="POST">
  <input type="hidden" name="access_key" value="המפתח-של-רועי">
```
ואז להסיר את ה-`e.preventDefault()` ב-`js/app.js`.

### 2. ⚠️ תוכן שממתין לאישור רועי
- **תאריך סיום יום 14** — במקור הישן נכתב `26/10` בעוד הטיול נגמר 17/10. באתר החדש רשום "יציאה לשדה התעופה ונחיתה בישראל" בלי תאריך, עד לאישורו.
- **יום 11** — המשפט במקור נקטע באמצע (`כפר של בני קבוצה אתנ`). הושלם כאן ל"כפר של אנשי הגורונג שמוצאם מטיבט". **דורש אישור.**

### 3. מספר וואטסאפ
כרגע מוגדר של רועי. משנים ב-`js/app.js`, שורה 8:
```js
var WA_NUMBER = '972544772010';
```

### 4. אנגלית — פעילה ✅
לחיצה על `EN` מחליפה את כל האתר: הטקסטים, **כיוון הקריאה (RTL↔LTR)**, 14 ימי המסלול, 14 ההמלצות, שמות תחנות המסע והודעת הוואטסאפ. הבחירה נשמרת ב-`localStorage`.

- `js/i18n.js` — מילון הממשק
- `js/data-en.js` — המסלול וההמלצות באנגלית

**שווה שדובר אנגלית ילטש** את הניסוח השיווקי לפני עלייה לאוויר.

## נגישות ו-SEO — מה כבר נעשה

- ✅ `<meta name="robots" content="index, follow">` — האתר הישן היה `noindex`
- ✅ JSON-LD: `TravelAgency` + `TouristTrip` + שלוש הצעות מחיר
- ✅ H1 יחיד, היררכיית כותרות תקינה
- ✅ RTL מלא · `lang="he"` · `dir="rtl"`
- ✅ אקורדיון עם `aria-expanded` / `aria-controls`
- ✅ מיקוד מקלדת נראה לעין
- ✅ `prefers-reduced-motion` מכובד
- ✅ טלפונים לחיצים · אפס גלישה אופקית
